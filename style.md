# Style Guide

## Design Principles
- **Clarity**: UI should be intuitive and easy to understand.
- **Consistency**: Repeated elements should look and behave the same.
- **Accessibility**: Ensure sufficient contrast and keyboard navigation.

## Color Palette
- Primary: `#3B82F6` (Blue 500)
- Secondary: `#10B981` (Green 500)
- Background: `#F9FAFB` (Gray 50)
- Surface: `#FFFFFF` (White)
- Text: `#111827` (Gray 900)
- Muted: `#6B7280` (Gray 500)

## Typography
- Font Family: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, "Apple Color Emoji", "Segoo UI Emoji", "Segoo UI Symbol"`
- Base Size: `16px`
- Line Height: `1.5`

## Component Conventions
- **Buttons**: Primary button uses primary background color, white text, rounded corners (4px). Secondary button uses transparent background with secondary text color.
- **Inputs**: Border 1px solid `#D1D5DB`, padding 8px, rounded corners (4px), focus ring using primary color.
- **Checkboxes/Radio**: Consistent size (16x16), consistent spacing.

## Dark Mode
- Invert background and surface colors.
- Adjust text colors to maintain contrast.
- Keep primary accent color.
